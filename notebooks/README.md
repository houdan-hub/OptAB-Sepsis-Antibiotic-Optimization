# Notebooks

This directory contains Jupyter notebooks for exploratory data analysis and result visualization.

## Planned Notebooks

1. `exploratory_analysis.ipynb` - MIMIC-IV data exploration, variable distributions, missingness patterns
2. `prediction_visualization.ipynb` - Plot SOFA/side-effect predictions, MSE heatmaps
3. `counterfactual_analysis.ipynb` - Counterfactual matching results, treatment comparison
4. `optimization_demo.ipynb` - End-to-end treatment optimization demo on sample patients

## Usage

```bash
jupyter notebook notebooks/
```

Note: Full MIMIC-IV data requires credentialed access via PhysioNet. The `mimic-iv-demo` subset can be used for initial exploration.
